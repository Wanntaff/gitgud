# TKJ 27 Class Profile Suite Plugin

Plugin workspace terpadu untuk project profil kelas TKJ 27 (SMK Negeri 3 Yogyakarta).

## Yang Termasuk di Dalam Plugin Ini:
1. **Skills:**
   - `anti-ai-slop`: Panduan dan filter ketat mencegah pola desain generik AI.
   - `modern-ui`: Panduan desain & implementasi Next.js/Tailwind modern.
   - `ui-ux-pro-max`: Panduan sistem desain menyeluruh, tipografi, dan palet.
   - `component-reference-design`: Pustaka referensi positif pola komponen modern.
2. **Rules:**
   - Git Safety protocol (no hard reset, no force push, no git clean).
   - Aturan konfirmasi penghapusan file.
   - Kewajiban penjelasan perintah terminal.
   - Next.js App Router & React 19 standards.
   - Anti-AI Slop guidelines.
3. **MCP Servers:**
   - `context7`: Upstash Context7 MCP server.
   - `shadcn`: Shadcn official MCP server.
